# 📋 Функциональность админ-панели

## Просмотр полной информации о пациенте

### 🆕 Новая возможность

На странице админа теперь доступна кнопка **"Детали"** для каждой консультации, которая открывает модальное окно с полной информацией о пациенте.

### 📊 Что отображается в модальном окне:

#### Основная информация:

- ✅ Имя пациента
- ✅ Возраст
- ✅ Пол (если указан)
- ✅ Телефон (если указан)
- ✅ Email (если указан)

#### Медицинская информация:

- ✅ **Рост** (в см)
- ✅ **Вес** (в кг)
- ✅ **ИМТ** (индекс массы тела)
- ✅ **Уровень боли** (0-10) с визуальными индикаторами
- ✅ **Обследования** (в виде тегов)
- ✅ **Хронические заболевания** (выделено цветом)
- ✅ **Лекарства** (выделено цветом)

#### Жалобы и примечания:

- ✅ **Основная жалоба** (полный текст)
- ✅ **Дополнительные примечания** (если есть)

#### Служебная информация:

- ✅ **Текущий статус** с возможностью изменения
- ✅ **Дата создания** заявки
- ✅ **Дата последнего обновления**

### 🎯 Функции в модальном окне:

1. **Изменение статуса** - выпадающий список с опциями:
   - Очікує (PENDING)
   - В процесі (IN_PROGRESS)
   - Завершено (COMPLETED)

2. **Кнопка "Закрити"** - закрывает модальное окно

### 📱 Адаптивный дизайн:

- Модальное окно адаптируется под размер экрана
- На мобильных устройствах информация отображается в одну колонку
- На десктопе - в две колонки для удобства просмотра

### 🎨 Визуальные элементы:

#### Уровень боли:

Отображается числом и визуальными индикаторами (красные точки):

```
Уровень боли: 7  ●●●●●●●○○○
```

#### Обследования:

Показываются в виде цветных тегов:

```
[Огляд] [Аналізи] [УЗД]
```

#### Хронические заболевания:

Выделены красным фоном для привлечения внимания

#### Лекарства:

Выделены желтым фоном для быстрого распознавания

### 🚀 Как использовать:

1. Откройте страницу админа: `/admin`
2. Найдите нужную консультацию в списке
3. Нажмите кнопку **"Детали"** справа от селектора статуса
4. Просматривайте всю информацию в удобном модальном окне
5. При необходимости измените статус прямо в модальном окне
6. Нажмите **"Закрити"** для возврата к списку

### 🔧 Техническая информация:

- Компонент: `DetailsModal` в `/src/app/admin/page.tsx`
- Адаптивная верстка с Tailwind CSS
- Поддержка темной темы
- TypeScript типизация для безопасности данных
